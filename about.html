About Me

Building toward AI engineering from strong software fundamentals.

My work spans machine learning fundamentals, transformer implementation, and applied AI. I have reimplemented GPT-2 in PyTorch, trained an anomaly detection system for an autonomous vehicle, and built a backpropagation engine that I used to train a neural network.

I am seeking an AI, machine learning, or software engineering internship where I can contribute to model development and the systems that make intelligent products reliable.

Interests

  • Transformer architectures, language models, and efficient model training.
  • Applied AI for autonomous systems, anomaly detection, and operational visibility.
  • Machine learning fundamentals, including gradients, backpropagation, and neural networks.
  • Production-minded AI systems supported by reliable backend and cloud infrastructure.

Experience highlights

  • Research Scholar and Project Manager in the CCI Scholars program, developing AI-powered anomaly detection for an autonomous vehicle.
  • Reimplemented the GPT-2 transformer architecture and built a stability-focused PyTorch training pipeline.
  • Teaching Assistant at James Madison University, tutoring more than 50 students in computer science topics and live-coding Python labs.
  • Hands-on builder across AI/ML, cloud pipelines, full-stack applications, and security-oriented software.

How I approach projects

  • I implement core ideas myself when doing so will deepen my understanding of the tools I use.
  • I approach model architecture, data flow, training stability, and application behavior as connected problems.
  • I value measurable iteration, clean experiments, and implementation choices that are easy to explain.
  • I like AI projects that move beyond a demo and serve a real operational or user need.
